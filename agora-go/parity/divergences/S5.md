## Kotlin behaviours reproduced on purpose (found with the scenarios)

* The page size and the offset are ignored by the Strapi queries: every page of the finished list (and of the answered list) shows the **same** consultations (the first 100 that
  Strapi returns, for the territory), and only `maxPageNumber` and the existence of the page change. A page exists when `(pageNumber - 1) * size <= count` (not `<`:
  page 2 of exactly 100 finished consultations exists), computed in Kotlin `Int` arithmetic: page 21 474 838 of 100 overflows to a negative offset and exists, `2147483647` gives
  an offset of -200 and exists. `maxPageNumber = ceil(count / size)`.
* The count of the finished consultations (`meta.pagination.total` of the unfiltered query) ignores the territory: `territory=Nord` with 230 finished consultations has `maxPageNumber 3`.
* `territory` is checked after the page (page <= 0 gives 404 whatever the territory); an unknown territory is a 400 `{"title":"Le territoire X n'existe pas."}`; the match is
  case-insensitive (`lowercase()`); repeated `territory` parameters are joined with `,` (so invalid). A finished page that does not exist is a **404 without body**, an
  answered page that does not exist (or a page number that is not an Int) is a **400 `{}`**. A finished page number that is not an Int is a Spring 400 (hex `0x1` is accepted: `Integer.decode`);
  the answered one is read with `toIntOrNull` (`0x1` is refused, `+1` and `-0` accepted).
* Without `territory` the page number is not looked at at all (page 0, -1 or 99999 give the list, `maxPageNumber 1`).
* The answered consultations: a consultation unknown to Strapi, or whose thematique is not in the thematique list, is dropped from the list but counted in `maxPageNumber`
  (`count(DISTINCT consultation_id)`); Strapi caps the list at 100 ids.
* The thematique list is read after the consultations (answered) / before (finished); an unavailable thematique list gives an empty page, cached like any other page.
* `Cache-Control: max-age=300, public` on `/concertations` only; the finished and answered lists have no cache header. All three routes are authenticated (401 otherwise).
* Concertations: a thematique that is not in the thematique list drops the concertation; sorted by `datetime_publication` descending, stable; the image is `image.formats.medium.url`, else `image.url`,
  else `image_url`; the territory is always `France`; any unreadable concertation (missing / null required field, bad date) makes the whole Strapi list empty (`[]`).
