# Slice S9 - divergences

No class C divergence introduced by the S9 code. Everything below is class A (same observable bytes) or B (fresher / cheaper), listed for transparency.
Differences caused by the foundations are in `parity/ledger/S9.md` ("Foundation findings") and scenarios tagged `S9-known`.

| id | class | Kotlin | Go | observable effect |
|---|---|---|---|---|
| B-S9-1 | B | content pages (`/content/*`), `/welcome_page/last_news` and `/participation_charter` call Strapi at every request (no cache) | one Strapi load shared for `AGORA_MICROCACHE_TTL` (default 5 s, singleflight): kept for successful loads of the pages and the charter, for a non-empty news list only; a failure or an empty news list is never kept | a change made in Strapi shows up at most 5 s later (`AGORA_MICROCACHE_TTL=0` disables the retention); `beginDate <= now` is still evaluated per request; the charter's `datetime_debut < now` Strapi filter is evaluated up to 5 s late |
| S9-1 | A | `fichesInventaireCache` in Redis (`shortTermCacheManager`, 5 min), key `toCacheKey`, empty lists and Strapi failures cached | process L1 (same key, same 5 min TTL, same rules, FLUSHDB-aware, concurrent misses share one load) | none: responses identical; each Go instance loads Strapi once per key and TTL instead of one Kotlin instance sharing Redis |
| S9-2 | A | `POST /feedback`: Hibernate `save` of an entity with the preset id `0000...` = SELECT then INSERT with a generated UUID | one `INSERT` with `gen_random_uuid()` (random v4) and `created_date` truncated to the millisecond (`java.util.Date`) | none: same row, one query fewer |
| S9-3 | A | `FicheInventaireNotFound` -> `@RestControllerAdvice` | `httpx.AdviceError{404}` | none (also verified with `?mediaType=xml`) |

Behaviours that look like divergences but are the Kotlin ones (kept on purpose):

* a Strapi failure on a collection route is an empty list: `/welcome_page/last_news` answers 404, `/fiches_inventaire` answers `[]` **and caches it for 5 minutes**,
  `/fiches_inventaire/{id}` answers 404; a failure on a single type (`/content/*`) or on the charter answers 500;
* `?titre=null` (or any blank filter) shares the cache key of an unfiltered `/fiches_inventaire` request; list filters are sorted in the key only;
* repeated `titre` / `thematique` / `anneeDeLancement` parameters are joined with `,`; repeated list parameters are not split;
* one undecodable element (a date Jackson refuses, a missing required field) makes the whole Strapi list empty; `LocalDate` accepts JSON integers as epoch days;
* an unknown feedback type is `400 {}`, a number is coerced to a String type first; a NUL character or a device value of more than 255 characters is a 500 and stores nothing.
