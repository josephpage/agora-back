# S4 divergences (consultation details)

No class C divergence caused by S4 itself. The differences that remain on S4 routes come from the foundations
(XML of a null list, XML request bodies) and are listed under "Foundation findings" in `parity/ledger/S4.md`,
each with a skipped scenario (`parity/scenarios/S4_known_foundation_diffs.yaml`, tag `S4-known`).

## Kotlin behaviours reproduced on purpose (found with the scenarios)

* The details of a consultation are public (`GET /v2/consultations/**`) and read the **unpublished** consultations (`status=draft`): an unpublished consultation
  is shown to everyone, by id or by slug. The slug query is tried first (`filters[slug][$in]`), then the id query.
* `getConsultationById` also asks for the drafts, and the questions route resolves ids only (`/consultations/consultation-1/questions` gives an empty `QuestionsJson`, 200).
* The latest update is the latest **other content** published, even when the sponsor's answer or the analysis is more recent; then the sponsor's answer, then the analysis,
  then the content shown after the answer. The history lists newest first after the fixed entries; the `CURRENT` entry follows the same priority.
* `ConsultationDetailsV2UseCase` reads the feedback flag before looking at the question, `ConsultationDetailsUpdateV2UseCase` after (a garbage flag is a 500 on one and not the other).
* The feedback of the details route is read from the database at each call; `results` of the feedback question only exist for a user who answered it; the statistics exist when the flag is on.
* `POST .../feedback` accepts the update by **document id only**, of a consultation by **document id only**, and only for updates that carry a feedback question (everything but the content shown before the answer); a missing
  `isPositive` is `false`; the answer is stored before the statistics are computed (a garbage flag is a 500 after the write).
* `UNIVERSAL_LINK_URL` unset gives the share text `null/consultations/<slug>`.
* The JSON "null elements" of Strapi lists (`[null]`) are accepted by Jackson and fail later (NullPointerException / NoWhenBranchMatchedException, HTTP 500): reproduced (`S4_invalid.yaml`).
* A consultation that cannot be read (bad date, missing required field, unknown `__component`...) makes the whole Strapi list empty: `404` on the details, empty questions, no consultation in the preview.
* `Territoire.of(profile)` returns an empty list (the territories are not used yet) but the profile is still read for a signed-in user.
