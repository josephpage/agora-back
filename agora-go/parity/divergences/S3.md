# S3 divergences

No class C divergence caused by the routing, the SQL, the Strapi requests or the mappers of S3: the scenarios, the oracle tests and the
ported unit tests find the two backends identical on every S3 route. The class B entries are the micro-caches decided by the product
(shared, non user-specific data may be cached for at most `AGORA_MICROCACHE_TTL`, 5 s by default) and one JVM-only corner (C-S3-SURROGATE)
that follows the already recorded `C-LONE-SURROGATE`.

## Behaviours that look like divergences but are the Kotlin ones (kept on purpose)

* `GET /v2/qags`: `offset > count` is a 400 but `offset == count` is a 200 with an empty list (and `maxPageNumber` = pages of the count); the offset is Int arithmetic
  (`(pageNumber - 1) * 20`): `pageNumber=1073741825` gives offset 0 (the first page, without header), `pageNumber=107374184` a negative OFFSET (PostgreSQL error, 500).
  The trending tab ignores `pageNumber` (but it must be an Int), `thematiqueId` and returns `maxPageNumber` 1; the "supporting" tab count keeps the SQL precedence quirk of the thematique variant.
* `GET /v2/qags` trending: the QaGs accepted twice appear twice (`getTrendingQagsV3` has one row per `qag_updates` row); an unknown weekly theme means "free theme" (clusters are applied);
  a Strapi failure of the clusters / headers means "no cluster / no header" (a failed header is kept as "not found" for an hour).
* `GET /qags/responses`: a response older than `minDate` is dropped *before* the split, so its QaG is listed as waiting for its response (`incomingResponses`); at most 5 responses are kept.
  `minDate` is parsed by `SimpleDateFormat("yyyy-MM-dd")` non lenient: text after the day is ignored (`2024-01-01T10:00` is valid), numbers may have any length / Unicode digits / an exponent (`2E3-1-1`),
  the Julian calendar before 1582-10-15 (1500-02-29 is valid, 1700-02-29 is not); the Go port is fuzzed against the JVM (`TestOracleMinDate`). It assumes a JVM default locale with ASCII digits and `-`
  (en, fr); the reference runs with the process locale.
* `GET /qags/responses/{n}`: `n <= 0` or `offset > count` is a **200 with no body** and `Cache-Control: max-age=300, public` (even with `?mediaType=foo`); the offset wraps like an Int.
* `GET /qags/search`: the keywords are cut at 75 UTF-16 units, diacritics removed, everything outside `[A-Za-z0-9 ]` dropped; fewer than 3 characters (spaces count) is a 404 `{}`.
* Anonymous requests never reach the handlers (401 from the security rules), so the `getUserId()!!` NPE of the Kotlin controllers is unreachable.
