## Exported services (for the other slices)

```go
import "agora/internal/modules/thematique"
th := thematique.Get(a)
th.List(ctx)          // []Thematique  ThematiqueRepository.getThematiqueList(): Strapi order, empty when Strapi fails
th.Sorted(ctx)        // []Thematique  ListThematiqueUseCase.getThematiqueList(): by label, "autre" last (GET /thematiques order)
th.ByID(ctx, id)      // *Thematique   ThematiqueRepository.getThematique(id): first match, nil (+ log "Thematique id '<id>' non trouvée") if none
thematique.ToJSON / ToListJSON / ToNoIDJSON   // ThematiqueJsonMapper (ThematiqueNoIdJson is embedded by consultation, concertation, fiche inventaire, QaG, response QaG DTOs)

import "agora/internal/modules/themehebdo"
t := themehebdo.Get(a)
t.Current(ctx)        // (ThemeHebdo, error)  getCurrentThemeHebdo(): cached 5 min (always, like Kotlin); trending QaGs only need .EstThemeLibre
t.Theme(ctx)          // (ThemeHebdo, error)  getThemeHebdo(): uncached
t.List(ctx)           // ([]ThemeHebdo, error) ThemeHebdoRepository.getThemeHebdoList(); shared slice, read-only
t.IsInTransition(ctx) // (bool, error)        IsThemeHebdoTransitionUseCase.isInTransition() (weekly tasks)
```

* `error` of themehebdo = an exception Kotlin does not catch (a Strapi date `OffsetDateTime.parse` rejects, or a
  `null` element of the Strapi list): an HTTP handler must `panic(err)` (500), a task fails like the Kotlin one.
* `thematique` has no error: Strapi failures give an empty list (Kotlin `StrapiDTO.ofEmpty()`).
* Returned `[]Thematique` are copies; `ThemeHebdo` values share their `ProchainsThemes` slice and pointers: treat as read-only.

## Quirks reproduced (all verified against the JVM)

* `/thematiques`: `Cache-Control: max-age=300, public`, ETag by httpx. Sort = `compareBy({id == AUTRE}, {label})`,
  stable, `String.compareTo` = UTF-16 code unit order (differs from Go's byte order for supplementary characters).
  A null element of `data` makes the Kotlin mapper throw (500): `[]*strapiThematique` + panic.
* `/theme_hebdo`: `Cache-Control: max-age=10, public`; dates formatted `ISO_OFFSET_DATE_TIME` in `Europe/Paris`
  (seconds always, fraction trimmed, `+HH:MM[:SS]` or `Z`, years > 9999 with `+`); a null date = NPE = 500 (unreachable
  from the controller, ported anyway in `ToJSON`).
* Strapi dates are parsed like `OffsetDateTime.parse` (STRICT resolver, case-insensitive `T`/`Z`, *lenient* offset
  `+HH[:mm[:ss]]`, fraction 0-9 digits, year 4-10 digits with `+` beyond 4, `Date.from` overflow): any rejected date
  fails every `/theme_hebdo` request with 500 (also when it belongs to a past theme), not cached.
* `periode`: empty -> generated from the UTC dates (`19-25 mai` / `26 mai - 1 juin`, months compared without the year,
  French month names), then `uppercase()` = `toUpperCase(Locale.ROOT)` (full case mapping, Unicode 13 like Java 17).
* Default theme dates: Monday 00:05 UTC / Sunday 23:55 UTC of the UTC week; `est_theme_libre` replaces `sousTitre`;
  `prochainsThemes`: strictly later start, stable sort by start, 3 max; first matching theme wins; bounds inclusive.
* `avatarUrl` is `null` (not the default avatar) for a Strapi theme without photo; default avatar only for the default theme.
* `isInTransition`: `|now - bound| <= 6 h` on debut or fin, `Math.abs` wrap-around kept.

## Foundation requests (nothing under `internal/{httpx,jsonjava,xmljava,cache,javacompat,...}` was modified)

* **F1 - httpx, 406 keeps the handler's headers.** With `?mediaType=foo` Spring answers 406 *without* the entity's headers
  (reference: `Cache-Control: no-cache, no-store, max-age=0, must-revalidate`, `Pragma`, `Expires` from Spring Security),
  httpx writes the handler's `Cache-Control: max-age=...` first. In `Server.finish`, ignore `resp.Headers` when
  `negotiate` returns "". Workaround in S0: each handler skips `CacheControl` when the mediaType is not json/xml/empty
  (`cacheControl` helper at the end of the 3 module files, delete once fixed). Every slice returning
  `.cacheControl(...)` or extra headers has the same issue.
* **F2 - httpx, `If-None-Match: *` is not a match.** Spring 6 `ServletWebRequest.validateIfNoneMatch` only extracts quoted
  ETags (`\*|\s*((W/)?("[^"]*"))\s*,?`, group 3), so `*` never matches: the reference answers 200, httpx 304
  (`ifNoneMatchMatches`). Scenario `s0-known-foundation-diffs-etag` (tag `S0-known`).
* **F3 - xmljava, `>` in text.** Woodstox writes `>` unescaped in text content (observed: `a>b` -> `a>b`, `<&>` ->
  `&lt;&amp;>`, `]>` -> `]&gt;`, a leading `>` -> `&gt;`; but a longer text `Zoé "Quote" <&>` -> `...&lt;&amp;&gt;`, so the rule also
  depends on the writer buffering); xmljava always writes `&gt;`. Scenario `s0-known-foundation-diffs-xml-gt`
  (tag `S0-known`); the S0 scenarios and oracle tests avoid `>` in XML text.
* **F4 - javacompat, missing helpers**: `String.compareTo` (UTF-16 order) and `String.uppercase()` (full case mapping, JDK 17 =
  Unicode 13) are implemented locally (`thematique/usecase.go` `compareUTF16`, `themehebdo/upper.go` `kotlinUppercase`, checked
  against the JVM for every code point). Other slices needing them should get them promoted into javacompat.
* **F5 - jsonjava, null elements of lists**: `[]Struct` decodes a JSON `null` element as a zero struct (the code comment says so),
  while Jackson keeps a real `null` (the Kotlin code then throws an NPE on non-null parameters). S0 decodes
  `Envelope[*Struct]` to see them. Slices decoding lists of Strapi DTOs may want the same.
* **F6 - oracle**: one line added to `parity/oracle/java/Functions.java` (`S0Functions.register(F);` at the end of `register`),
  the only way to register new functions; everything else is in the new `S0Functions.java`. Expect a trivial merge conflict
  there when several slices add their own line.
* **F7 - harness race (changed)**: the runner publishes the L1 invalidation after `FLUSHALL` and goes on at once; the Go subscriber
  applies it asynchronously, so the first request of a scenario was sometimes (about 1 run in 6, a few ms scheduling delay) served
  from an L1 entry of the previous scenario. `parity/runner/env.go` `reset` now sleeps 50 ms after the publish (3 lines). Every slice
  with an L1 cache is exposed to the same flake without it.
* `gofmt -l` reports foundation files that are not gofmt-clean (`internal/auth/oracle_test.go`, `internal/config/config.go`,
  `internal/httpx/response.go`, `internal/javacompat/javacompat.go`, `internal/strapi/{client,richtext}.go`); S0 files are clean.
