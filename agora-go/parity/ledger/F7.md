# F7 - `internal/sanitize` (ContentSanitizer)

Go port of `fr.gouv.agora.usecase.qag.ContentSanitizer.sanitize(content, maxLength)`:

```kotlin
HtmlUtils.htmlUnescape(HtmlPolicyBuilder().toFactory().sanitize(content)).take(maxLength)
```

Package API (`agora/internal/sanitize`):

| Go | Meaning |
| --- | --- |
| `Sanitize(content string, maxLength int) string` | what the use cases call; the result is what PostgreSQL stores (a lone UTF-16 surrogate becomes `?`, like the JDBC UTF-8 encoding of the Java string); panics for a negative `maxLength` like Kotlin `take` |
| `SanitizeUTF16(content []uint16, maxLength int) []uint16` | the exact Java `String` (UTF-16 code units, lone surrogates included) |
| `Raw`, `HTMLUnescape` | the two stages alone (tests/debugging) |

### Reduction of the OWASP pipeline for the empty policy

`HtmlPolicyBuilder().toFactory()` allows no element: the policy never writes a tag and never closes one, its only state is
`skipText` (set by `openTag` when the element is one of script/style/noscript/nostyle/noembed/noframes/iframe/object/frame/
frameset/title, reset by every `closeTag`), and the renderer therefore only receives `text()` in PCDATA mode.
The balancer is kept in full because the elements it opens/closes/resumes call the policy (changing `skipText`), because it
drops inter-element whitespace and because events are dropped beyond a nesting depth of 256. Not ported, because they cannot
influence the output of the empty policy: attribute name/value processing (`canonicalAttributeName`, `stripQuotes`,
`decodeHtml(.., inAttribute = true)`; the tokens are still consumed), `closedOnOpen/closedOnClose/explicitClosers`
matrices (unused by the balancer), the renderer's tag/CDATA writing, `HtmlChangeReporter`, element/attribute policies.

### Quirks reproduced (all confirmed by the oracle)

* `{{x}}` -> `{<!-- -->{x}}` and a trailing `{` -> `{<!-- -->` (the encoder splits template brackets and nothing removes the comment).
* Supplementary characters: OWASP writes `&#x1f600;`, Spring casts the value to `(char)`: U+1F600 becomes U+F600; U+1D800 becomes a
  lone U+D800 (stored as `?`), U+1D800 U+1DC00 becomes a valid U+10000 that `take(1)` splits (`?`).
* `<textArea>` (mixed case SVG name) is not the RCDATA `textarea`; `<noscript>a<b>c</b>d` keeps `c`/`d` but `<noscript>a</b>c` keeps nothing;
  `<title>`/`<iframe>`/`<script>` content is dropped, `<select>a` keeps `a` (implied `<li>`, "opgroup" typo of `HtmlElementTables`);
  text after 256 open elements is dropped; the ZWNJ before an Indic vowel is dropped; controls, U+FFFE/U+FFFF and lone surrogates are elided.
* Spring: numeric references go through `Integer.parseInt` (sign, any script's digits, overflow = not a reference) and `(char)`.

## Fast path

`Sanitize` returns `Take16(content, n)` without running the pipeline when `isPlainText(content)` (no `<`/`&`, no control, no `{{` or final `{`,
no supplementary char, no U+093A-U+0C4C Indic range, no U+1FEF, nothing from U+FE60): the whole pipeline is then the identity
(characters that the encoder writes as a reference, such as `'`, `"`, `+`, `=`, `>`, `@`, `` ` ``, are decoded back by Spring). It is
proven equivalent by `TestOracleFastPath`, `TestOracleFastPathEveryRune` and `TestFastPathEqualsGeneralPath`. Typical French sentences
of a hundred characters take about 230 ns and no allocation on this path, about 4 us on the general path, about 23 us for a
350-character HTML snippet (`BenchmarkSanitize*`, 4 cores).

## Foundation requests / notes to the lead

* Decoding of request bodies (`internal/jsonjava`, `encoding/json`) replaces a lone surrogate escape (`"\ud800"`) by U+FFFD, whereas Jackson keeps
  it as a lone surrogate, which the OWASP encoder then elides: `{"x":"a\ud800b"}` sanitizes to `ab` in Kotlin and to `a<U+FFFD>b` in Go.
  `SanitizeUTF16` can take the exact units if the JSON layer is ever able to provide them. Also see the divergences file.
