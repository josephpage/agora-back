## Reproduced Kotlin quirks (all checked on the reference through the scenarios)

* `AgoraQueue`: a second concurrent action of the same user and type is a 400 (`parallel:` scenarios); Add/Remove support are different tasks;
  the three queues are independent. An exception inside a queued action leaves the user locked on the Kotlin side until it restarts
  (B-AGORAQUEUE): the Go lock is released by `defer`. **Restart the reference (`restart-ref`) before every S2 run**, and never reuse a user
  that made Kotlin throw (the scenarios use a dedicated user for each such step).
* Details: the thematique is looked up before the status (unknown thematique = 404 even for a rejected QaG); an open QaG is visible to its author only
  (the comparison is on the id string of the principal); `responseDate` is the Strapi day with the CURRENT time of day (`LocalDate.toDate()`),
  `transcription` has its `\n` sequences unescaped in `QagJson` only; `feedbackResults` are dropped when the user gave no feedback; a selected QaG
  is always "supported"; a Strapi failure or an empty answer = no response (the QaG is still returned); a response without `reponseType`
  is a 500 (`first()`); the first response type decides; unknown/missing `__component` or a missing required field anywhere = empty Strapi list.
* `reponseDate` is read like Jackson's `LocalDateDeserializer` (`javadate.go`): `yyyy-MM-dd` strict (EXCEEDS_PAD year), date-times
  (`...T..`, optionally `Z`), `[y, m, d]` arrays, integers as epoch days; years above 9999 are formatted `+12026-...` like `yyyy`.
* Support: `OPEN` and `MODERATED_ACCEPTED` only (a user can support the open QaG of another user, it is not listed afterwards); duplicate rows count once; delete removes
  every row of the pair; an invalid status or a NULL column makes Kotlin throw (500) where the one-statement path would have acted: the statements exclude
  such rows and the Kotlin sequence is replayed to raise the same exception.
* Insert: no feature flag, one QaG per week from Monday 10:00 (the Monday bound keeps the nanoseconds of `now`), `thematiqueId` is stored as is (any string up to 255 chars,
  longer = 500), fields are sanitized after the lenient Jackson decoding (numbers/booleans become strings).
* Feedback: stored for any `qagId` string (raw, not a UUID: lenient uppercase ids are different keys), before the response too; a `qagId` longer than 255 characters is a 500
  after nothing was written; with the feature flag off the feedback is recorded and the answer is `{}`; a garbage flag value is a 500 after the row was written.
* Ratios: `(helpful * 100.0 / total).roundToInt()`, negative = 100 - positive, none = 0/0/0 (fuzzed against the JVM).

## Foundation findings (nothing under `internal/{httpx,jsonjava,xmljava,cache,javacompat,...}` was modified)

1. **Request layer**: before the lead's request-layer commit three families differed (no `Content-Type` + no body = 400 on Kotlin; 415 `Accept` list;
   `Allow` separator; Latin-1 `User-Agent` in the suspicious-origin check). They pass after the merge (`S2_request_layer.yaml`).
2. **`Allow` order is not stable on the Kotlin side** for a path with several methods (405 and OPTIONS): the reference gave `DELETE, POST` /
   `DELETE,GET,HEAD,OPTIONS` in some JVM runs and the registration order in others. The S2 scenarios only keep 405s with a single allowed method.
3. **jsonjava, integers beyond int64 as Boolean**: `{"isHelpful":12345678901234567890}` is a 200 for Jackson (BigInteger != 0 = true), a 400 for Go
   (skipped scenario `S2-known-foundation-diffs-jackson-number-coercion`; the oracle test leaves that literal out).
4. **jsonjava, lone surrogate escapes** (`"a\ud800b"`): Jackson keeps the lone surrogate which the sanitizer drops (stored `ab`); Go decodes U+FFFD (stored `a?b`).
   Already F7 finding 1; skipped scenario `S2-known-foundation-diffs-lone-surrogate`. `sanitize.SanitizeUTF16` would be exact with UTF-16 units from the JSON layer.
5. **`Content-Type: APPLICATION/JSON`** (upper case) on `POST /qags`: the reference answers 400, Go reads the body (200)
   (skipped scenario `S2-known-foundation-diffs-uppercase-media-type`).
6. **Missing helpers** implemented locally in `javadate.go` because no foundation package has them: Jackson `LocalDate` reading (`strapi` DTOs of S3 that read `LocalDate`
   should reuse it or get it promoted), and `DateMapper.toFormattedDate` for years outside 1..9999 (`formatDate`; `common.FormatDate` prints `12026-...` instead of `+12026-...`).
7. **`AGORA_COEXISTENCE` "cap Go caches"** is not implemented by `cache`: `coexistenceCap` (5 minutes) is applied locally to the two Kotlin-shared caches.
8. **Runner**: the generated id inside a non-JSON string (`path` of a Spring error body for an unknown id) is not bound: the step uses `compare.ignore: ["$.path"]`.
   And the in-JVM stuck locks of finding "AgoraQueue" make runs order-dependent unless the reference is restarted.
