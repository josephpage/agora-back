## Caches and performance design

| Kotlin | Go |
|---|---|
| none: count + page SQL at every `/v2/qags` (tabs top / latest) | **micro-cache** `qagListCount` (key thematique) and `qagListPage` (key tab, offset, thematique): `AGORA_MICROCACHE_TTL` (<= 5 s, `Cache.CoexistenceTTL`), singleflight, errors never kept, `context.WithoutCancel` for the shared load. `/qags/count` shares the count |
| `getUserSupportedQagIds` + `list.any{}` per QaG | **never cached**: one indexed query per request (Q6, < 0.3 ms), then a set lookup. The "supporting" tab and its count are personal SQL, read at every request; `isAuthor` compares the user id; so the user sees their own support / unsupport at once |
| `trendingQagCache` (5 min Redis, key `trendingQagList`, empty list kept) | L1 `trendingQagCache`, same key and TTL, `CoexistenceTTL` (5 s while both backends run: the counts are Kotlin-writable); the score / guards / clusters are computed per request on the shared candidates |
| `headersQag` (1 h, `""` = not found) | L1 `headersQag`, 1 h per tab, found or not found (also after a Strapi failure) |
| `trendingClusterCache` (5 min, non-empty only) | L1 `trendingClusterCache`, same rule |
| Strapi responses (no cache) | micro-cache `qagResponsesByIDs` / `qagResponsesAll` / `qagResponsesTotal`, non-empty answers only |
| `thematiqueRepository.getThematique` per QaG | `thematique.Service.ByID` (map lookup, never one Strapi request per item) |

No N+1: a page is 2 shared queries (cached) + 1 personal query; the paginated responses are 1 Strapi list (cached) + 1 `getQagsInfo` (`IN` list); the trending is 0 queries (cache) + the personal one.
Why the shared page is **not** invalidated by the user's own write: a burst of supports would clear the page cache at every support and put the 1 s+ aggregation back on the hot path (`PERF.md`); the counts of the shared pages lag by <= 5 s, the user's overlay is exact (divergences S3-B1).

## Reproduced Kotlin quirks (all checked on the reference)

* `GET /v2/qags`: count first, then `offset > count` (not `>=`) = 400, Int overflow of `(pageNumber - 1) * 20` (offset 0 for 1073741825, PostgreSQL error for 107374184), `pageNumber` of the trending tab only has to be an Int,
  the tab header only on page 1 (always on trending), a Strapi failure of the header is kept as "not found" for an hour, unknown thematique of a QaG drops the QaG from the page (the count is unchanged), repeated parameters are joined with `,`.
* Trending: first row pinned (`moderated_date DESC`), the other rows filtered by id (a QaG accepted twice appears twice), score `(likes + 1) / (hours + 2) ^ exponent` with whole hours (`Duration.toHours`), stable `sortedByDescending` with `Double.compareTo`,
  at most 3 QaGs older than 72 h, at most 9 slots, and in a free-theme week (the weekly theme *defaults* to free when Strapi has no current theme) at most 2 QaGs per cluster, rejection when any matching cluster is full, clusters sharing an id share their counter.
* `/qags/responses`: the response filter by `minDate` happens before the split; 5 responses at most; low-priority QaGs last; `order` is the index in the merged list; Monday of the QaG week; the `incomingResponses` support is always `isSupported: true`.
* `/qags/responses/{n}`: two Strapi requests (the plain collection for `meta.pagination.total` when there is no `minDate`, the sorted one otherwise and for the page), `subList` fails for a negative offset (500), the page is sorted again after the QaG join.
* `/qags/search`: see the route table; the 20 first results by support count.

## Foundation findings (nothing under `internal/{httpx,jsonjava,xmljava,cache,store,strapi,common,javacompat}` or `parity/runner` was modified)

1. **javacompat: no JVM `Math.pow`.** Go's `math.Pow` differs from the JVM for 80 % of the whole-number bases at exponent 1.5 (one ulp), which can reorder equal trending scores. `qaglist/javapow.go` (+ generated table) is exact for the default exponent; suggest promoting it, and
   `responseqag/mindate.go` (`SimpleDateFormat("yyyy-MM-dd")` non lenient, fuzzed against the JVM) next to the other `java.text` helpers.
2. **jsonjava: lone UTF-16 surrogates cannot be written** (C-S3-SURROGATE in the divergences): `String.take(n)` can cut a surrogate pair and Jackson writes `\uD83D`.
3. **parity fake Strapi: `POST /__control/override` rejects a JSON `null` element in `data`** (HTTP 400), so the "null element" branches (`HeaderQagStrapiRepository` `firstOrNull`, `TrendingClusterRepositoryImpl` NPE) have unit tests but no scenario.
4. `S9`'s `content.LocalDateTime` is imported by `qaglist` (see above): promote to `common`.
5. The reference JVM default locale matters for `SimpleDateFormat` (digits / minus sign): the port assumes ASCII (en, fr).
